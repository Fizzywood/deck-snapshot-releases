# Security

Do not open a public issue for a suspected Deck Snapshot vulnerability or for material containing credentials, tokens, recovery data, snapshot contents, or private paths.

Use GitHub's private vulnerability reporting for this repository if it is enabled. Otherwise contact the repository owner privately through the security contact listed on the owner's GitHub profile.

This repository must contain distribution artifacts and public distribution documentation only. Inspectable release-source snapshots belong in the separate public `Fizzywood/deck-snapshot-source` repository. If private development history, credentials, tokens, recovery material, or user data are accidentally published here, treat the channel as compromised: stop downloads, remove the affected release, rotate exposed credentials where applicable, publish a new immutable version, and document the affected digests.
